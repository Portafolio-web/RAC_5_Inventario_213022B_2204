## Descripción del proyecto

Este proyecto se desarrolló en Python con el fin de revisar el inventario de cinco (5) artículos y calcular cuántas unidades hacen falta para completar el stock mínimo.

## Funciones del programa

- **calcular_cantidad_a_pedir():** realiza el cálculo de las unidades que hacen falta.
- **procesar_inventario():** recorre los artículos y muestra los resultados en una tabla.
